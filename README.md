# API de Loja

Este é um projeto que desenvolvi para praticar Backend com JavaScript, Node.js e Express.

A ideia do projeto foi criar uma API simples de uma loja, onde é possível criar, buscar, atualizar e deletar produtos.

## Tecnologias utilizadas

- JavaScript
- Node.js
- Express

## Funcionalidades

Atualmente, a API permite:

- Listar todos os produtos
- Buscar um produto pelo ID
- Adicionar um novo produto
- Atualizar um produto existente
- Deletar um produto
